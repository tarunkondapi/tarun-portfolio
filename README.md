# Tarun Portfolio

A responsive personal portfolio built with React, Vite, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Add your resume

Place your PDF resume at:

`public/resume.pdf`

The Download Resume button will then work automatically.

## Deploy

Push this folder to GitHub and import the repository into Vercel.

Build command: `npm run build`
Output directory: `dist`
